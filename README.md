## Publicar no GitHub Pages

1. Crie um repositório e envie estes arquivos para a raiz (`index.html`, `.nojekyll`, `README.md`).
2. No repositório: **Settings → Pages → Build and deployment**.
3. Em **Source**, escolha **Deploy from a branch**; branch **main**, pasta **/ (root)**; clique em **Save**.
4. Em 1 a 2 minutos o site estará em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
